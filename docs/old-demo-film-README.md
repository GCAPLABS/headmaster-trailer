# Headmaster demo film, Remotion project

Phase A: storyboard (`storyboard.json`, `storyboard.md`, generated by `tools/sb.py`) plus scene 1 ("ask", 7.5 s).

- Render: `npx remotion render src/index.ts Opening opening.mp4` (about 30 s)
- Studio: `npx remotion studio`; stills: `npx remotion still src/index.ts Opening out.png --frame=100`
- Browser: no download needed; `remotion.config.ts` points at the Playwright headless shell.
- Fonts: Archivo (display) and Figtree (UI) in `public/fonts`. No Inter.

Licence: the Remotion free licence applies (individual, or a company of up to 3 employees).
Technique source: product-launch-video skill (MIT, memex-lab) and remotion-best-practices, used as guides only.

## FilmLong (v4)
