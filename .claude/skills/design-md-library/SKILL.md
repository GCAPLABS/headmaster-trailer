# DESIGN.md library

Copied from VoltAgent/awesome-design-md (MIT, see LICENSE). Each folder under `brands/` holds a `DESIGN.md`
(colour tokens, type scale, spacing, components, motion, do and don't) and a short README.

How to use it:

1. `ls .claude/skills/design-md-library/brands` to see the brands.
2. Read the one or two closest to the look you want; borrow principles and proportions, not logos or brand names.
3. Our own palettes still win: Studio skin (white, grey, royal blue #0000da) for desktop, web chat and iOS; the site keeps its own colours and fonts.
